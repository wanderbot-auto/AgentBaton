# ADR: optimize the unchanged SHA-256 dependency in development builds

Decision: use `opt-level = 3` only for the locked `sha2` package in the dev profile of both workspace roots. Cargo test inherits dev. The desktop has its own workspace, so it needs its own declaration. Release settings, dependencies, lockfiles, features, algorithm, executable sizes allowed by policy and all authorization checks remain unchanged. No global dependency optimization, CPU-specific flags or assembly feature is added.

At exact Root844d6a4, the real generated ACP/MCP/Goal test still failed in28.85s (49.16s including compilation). Its explicit debug-only trace measured four full86,288,696-byte companion checks. SHA update plus finalize/hex wall time was3078/3102/3093/3077ms inside read/hash spans3113/3136/3125/3109ms: aggregate12350/12483ms,98.9346%. These are wall intervals, not CPU measurements or98.9% of the whole test. The3136ms external check contains one of those spans and must not be counted again; the3024ms Provider verification is an outer call span. The independently retained15s observer was almost exhausted preparing the parent before Goal input observation began.

The normal development CLI is a legitimate large debug executable, roughly86MiB decimal bytes (exact size above); it remains an input to full integrity checks. Do not strip/shrink it, replace it with a mock, skip duplicate boundaries, reuse stale authorization proofs or raise the15s fixture observer,90s runner guard, Grant/Scope expiry, Node runtime budget or128MiB companion cap. Keep FD/no-follow/single-link/identity/mtime/ctime/hash/CAS/permission checks and single-worker behavior.

`sha2`0.10.9 has a non-generic compression core that can benefit directly from this override. Its generic digest/buffer wrappers may still be instantiated in consumers; this is a measured candidate, not a promise that every stage becomes fast. The current locks already pin sha2/digest/block-buffer. Native ARM and Intel may choose different default backends; no hardware-acceleration result is inferred. See independent source analysis32868e9a/ed638a4e and the actual844 trace.

Validation required before accepting the decision: independently review this exact diff; record actual Cargo/rustc optimization flags and new same-source binary manifests; measure the same full-size executable observation and compare its digest; rerun the exact real child and root-self lifecycle assertions under original limits with diagnostics disabled, then appropriate regression/Clippy/format, browser and exact dualMac CI. Separate local/profile/platform dimensions. Preserve all earlier failed runs and inspect failures without extending permissions. Compiler/storage/CI costs and performance improvement remain unmeasured until those runs finish.

Rollback is a two-table manifest removal. No production publishing, signing, private Provider identity or new account spending is authorized by this engineering decision. Full Design v0.2 remains in progress.
