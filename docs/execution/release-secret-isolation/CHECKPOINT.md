# AB-REL-005 检查点

普通 CI 的结构化静态检查和定向夹具已就绪。发布或真实账户的获批受保护 workflow、实际仓库环境能力与签名验收仍需另行验证。

BOOTSTRAP_MANIFEST.json 在相同 Environment 步骤中先校验检查器文件的摘要。冻结后由集成窗口更新此项并验证组合候选。工作流文件及权限配置的变更由相应授权单独管理。

本分支已验证原基线和冻结代码的实际静态入口、13 项定向以及 5 组基线反例。由于集成窗口负责在相同候选更新摘要并执行完整基础设施，当前留待组合验收的是成功的 bootstrap 校验、完整 Python 基础设施、Node 测试及 Rust smoke 和 Clippy。原日志见 logs，详情见 EVIDENCE.json。
