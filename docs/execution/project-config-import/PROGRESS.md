# AB-CFG-009 进展

- 新增只读项目配置检查与确认入口。已选项目根按设备和 inode 验证，固定项目和输入修订、Provider 版本、策略、存在或缺失的源、候选冲突及选定的计划。
- 复用 NativeSourceRoot、InstructionOnlySkill 和 RuntimePlan。Skill 仅接受已分类为非秘密且摘要一致的独立说明文件。MCP 可明确选择独立批准的托管定义。Hooks 仅记录事件和不可启用状态。原生命令、参数、地址、环境值、凭据及 Hook 正文从源读取后均不进入托管文件。
- 可信确认匹配私有目标根和完整快照摘要。托管快照使用 ManagedRoot 单文件原子发布，复用项目级锁及事务日志。重复确认返回同一持久状态。恢复根据日志与精确文件区分未应用、已应用和需对账。
- 发布沿用已验证的托管目录描述符。恢复还核对快照自身的项目 ID 与确认 ID，防止用同一文件冒充其他确认范围。
- 夹具使用实际 Git、项目配置文件和管理根。故障用例让操作系统在快照已发布后拒绝最终日志重命名，保留精确的阶段证据并对账。测试不调用实际 Provider、项目命令或网络。
- 已向集成窗口报告后续所需的可信项目与输入修订、专属托管根、MCP 注册表和一次确认记录。Core 项目接线、共享 IPC、App 原生确认界面及 Hooks 激活仍待独立工作。OWNER-003 不影响所需的首次配置授权。
