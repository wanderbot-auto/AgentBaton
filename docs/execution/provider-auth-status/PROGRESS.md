# Provider 认证状态进度

1. 在授权目标的准确基线建立专用工作树，预留 Provider 实现、独立测试及本目录。
2. 核对固定 CLI 的启动、配置、认证模式、退出码与输出内容。审阅 App Server 的账户读取和旧状态接口。生产调用当前缺少可验证运行策略。
3. 增加独立状态 API。仅允许固定 CLI 命令，验证摘要、审批和运行上下文，对输出做封闭投影。公开接口无法自行构造验证能力。
4. 生成夹具覆盖已识别状态、歧义、资源上限、退出与回收、执行前后摘要变化以及敏感输出脱离 API。公开负控验证缺少上下文、错误路由或版本时跳过启动。
5. 初始 Provider 全套中新增测试通过。原有安装探测夹具出现期限失败，独立重编基线复现。运行证据和验收环境见 EVIDENCE.md。
