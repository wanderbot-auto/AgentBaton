# AB-PRO-011 进展

- 实现了可供登记与派发接线的 `admit_managed_update`。以真实当前连接与安装、调用者可信解析的批准策略以及独立候选兼容观察为输入。返回同一连接的下一修订和新任务的精确绑定。
- 复用现有绑定和运行时能力校验。策略及兼容观察固定原连接修订、Provider、路由、执行模式、Host、身份、有效配置及摘要。安装批准引用、安装 ID、路径、程序版本、二进制摘要及支持清单也须一致。候选证据在策略时限内且来自候选版本探针之后。
- 已有任务和结果不明在文件读取前拒绝。托管目录须经可信策略固定且为规范路径。两个安装使用不同的安装 ID、文件、内容及支持清单，拒绝符号链接绕过和共享 inode 的硬链接。
- 私有合成程序执行真实 `--version`，入场检查现场重新计算新旧摘要。兼容证明采用合成记录。基线的旧安装探针并发测试出现超时，保留原始日志并对未改动的用例复跑。版本和结果见交付证据。
