# Fixed-command implementation progress

Implemented a real fixed-command runner and private trusted-host approval boundary in `crates/workspaces/src/command_validation.rs`. Neither rules nor successful tokens deserialize from Agent JSON. Approval labels alone are not authentication: a future Core caller must authenticate current owner approval/revocation before constructing the typed rule.

The serialized complete contract binds validator/mode, subject task/attempt/spec/input and version, pinned artifact roots/IDs/paths/SHA/limits, canonical program/argv0/literal argv, cwd identity, environment value digests, expected exit codes, process identity, image policy and all runtime/capture/enforcement limits. The receipt additionally binds its approval and policy revision. Raw environment values do not derive Debug/Serialize; raw captures are bounded private getter data for a trusted caller, not automatically persisted/redacted history.

Linux executes an approved ELF snapshot from sealed memfd bytes, so replacing its original path cannot substitute the running main image. macOS implements canonical system Mach-O paths whose file and all ancestors are root-owned, without group/world write bits and not writable by the same nonroot execution identity, including an ACL-sensitive access check. File identity, hash and permissions are rechecked after execution and at acceptance. Privileged OS updates, dynamic libraries, hidden native configuration and arbitrary auxiliary source are outside those assurances. macOS strict image sealing is unavailable and rejected; this is not a memfd emulation.

PosixShStdin uses only the fixed approved system interpreter, `-s --`, approved literal arguments and pre-read SHA-matched memory bytes. It never opens the script path for execution. Post-run script changes invalidate artifact evidence. The module rejects known sh paths in NativeExecutable; trusted host review must still establish the behavior of arbitrary native binaries and must not infer interpreter detection from that extra guard.

All command I/O is nonblocking and captured separately with per-stream limits. No reader thread joins can hang on inherited pipes. WNOWAIT retains the owned original leader until process-group signals finish. Only that owned group and direct Child are signalled. Cleanup has a separate monotonic bound; unreaped direct-child ownership is retained in CommandRun for nonblocking reconciliation. Escaped descendants are not searched for or signalled and containment remains unknown. The host must not install a global child reaper/change SIGCHLD disposition during a run; unsupported dispositions fail preflight.

The runner does not inherit the parent environment. Strict filesystem isolation, network isolation, full tree containment, execution-time input immutability and auxiliary-source immutability are rejected before spawn. Before/after equal hashes do not prove continuous immutability: an actual fixture changes and restores its input and the receipt accurately reports only before/after observations. Exit zero cannot override missing/unsafe/oversized/hash-mismatched artifacts.

Self-validation: 26 Linux command tests, 89 workspaces unit/integration tests total and 4 compile-fail doctests passed under umask 022. Linux and both macOS all-targets Clippy passed; both macOS checks are cross compilation only. The first Clippy invocation found one redundant unit expression; it was removed without changing guards or assertions and the failed log is retained. Independent review and actual macOS CI remain pending at this checkpoint.
