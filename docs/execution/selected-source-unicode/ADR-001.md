# Preserve raw UTF-8 and reject observed aliases

The earlier selected capture implementation intentionally supported ASCII only, rejecting even a valid unselected Unicode base entry. Full Designv0.2 did not approve that permanent product limitation. Removing is_ascii alone would leave case-only selected/base collisions and normalizing-host spelling aliases unresolved.

Use focaccia=2.5.0 full Unicode casefold comparison only for a private ordered collision key. Root checked the actual registry .crate59942B checksum d0d565312085d6ae0832a9f9efd76adf0983b924128f6ebe752009f63e70b8ee against the lockfile. It has no transitive dependencies and requires Rust1.85. The dependency's MIT AND Unicode-3.0 license does not select the project's final license. Its own versioned data is documented as Unicode18; no handwritten table or std to_lowercase substitute is used.

The public capability/result API, original path bytes, stable commit/object verification and approval/selection digest representation remain unchanged. NFC/NFD is not applied. Distinct canonical spellings on a filesystem that actually distinguishes them remain distinct Git names; when the real host resolves both to one identity, capture refuses instead of silently replacing a spelling. Full casefold collisions such as Straße/STRASSE and final-sigma/ordinary-sigma are rejected even when the old base entry is not checked out.

Actual selected spelling uses an owned descriptor-relative directory stream and openat/fstatat NOFOLLOW. It checks literal entry bytes and stamps, rejects observable case/inode aliases, then reopens only directory chains to recheck stamps. It does not keep one descriptor for every visited directory or open/close raw regular leaves for metadata, avoiding unnecessary regular-file POSIX lock interactions. readdir name reads are bounded by the actual d_reclen and d_name offset, not sizeof(dirent). Only Linux/macOS errno interfaces are enabled; other local platforms fail closed.

Full-base Git traversal keeps raw UTF-8, uses ordered selected-prefix lookups instead of a quadratic Unicode scan, and tests existing host identities when safely observable. An absent or non-checkout path is not fabricated as observed FS evidence. A virtual base entry still gets full casefold collision checks; host-specific normalization evidence is limited to actual same-inode lookups. No claim is made that this algorithm simulates every filesystem's Unicode collation on a different host.

Existing global15s,256 selected files,64MiB bytes and4096 encoded path bytes are unchanged. Each complete alias audit also caps actual directory names at65,536 entries/4MiB and prefix/identity caches at4MiB/65,536. They are shared over the audit, never reset per artifact, and can return ResourceLimit rather than truncate. Repeated final object/tree checks remain under the original capture deadline. Blocking kernel I/O is not claimed preemptible and no OS sandbox guarantee is added.
