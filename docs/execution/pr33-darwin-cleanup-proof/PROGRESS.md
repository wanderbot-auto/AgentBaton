# 执行进展

在 Apple Silicon macOS 26.6.1（25G76）和 Python 3.12.12 复现基准唯一的观测故障红灯。修复仅让 EPERM 走现有的新鲜组证明，并移除已无使用的旧 `exited` 状态。驱动实际对照采用上一轮固定诊断工具，只按 runner 快照调整预期断言。

确定性回归先等生成子进程进入 zombie，再注入观测错误和 EPERM。有效的生成报告仍被降为 failed，证明清理结论与观测失败各自独立。原超时、真实组和负控都通过。

历史反演为当前 runner 增加一层固定字节变换。当前 loader 更新输入 pin，原 Store19 层和 Store18 helper 字节逐一与 Git 原件核验。只提交脱敏摘要，原始直接测试及全量日志留在任务私有目录。
