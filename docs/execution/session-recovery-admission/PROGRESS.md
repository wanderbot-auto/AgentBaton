# AB-SES-006 进展

- `Supervisor::assess_session_recovery` 提供只读的 Rust 准入结果。匹配 session、attempt、dispatch intent 及原有任务和项目；现有或未对账的进程、turn、任务结果和写入者优先返回待对账。
- 复用 Core 的已批准执行绑定和现场工作区校验。历史输入修订、原始规格修订、当前连接及本地配置快照必须一致。原生资格还要求可信身份、原生会话 ID、成功探针、现场程序摘要和针对该版本的运行时加载能力证明。
- 缺历史绑定时保留待对账。已确认停止但缺少原生证据、工作区漂移或绑定失效时，建议新建尝试，并可携带此前由可信调用方选定且同项目、同任务、同尝试的交接引用及摘要。
- 定向用例运行实际 Core Store 和 Supervisor，生成私有 Git 工作区、SQLite 记录和 ACP 夹具进程。夹具运行原有通路，身份和兼容观察由测试提供。比较评估前后的记录和协议收包，验证准入没有创建尝试、加载会话或重放消息。
- 当前连接登记仍把身份记录为未知，并且 Core 尚未持久化原生加载能力或原始任务规格修订。已向集成窗口报告后续依赖。该补丁范围内无需修改共享 IPC 或数据库结构。
