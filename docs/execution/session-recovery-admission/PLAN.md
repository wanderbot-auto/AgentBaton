# AB-SES-006 会话恢复准入

认领基线 `315902e2c7c9e0c6dbaad8a22a5285009630d8ff`，分支 `collab/session-recovery-admission`。依据 AB-START-001、AB-SES-006 和 Provider 与会话第 8 节。

1. 用现有 Core 的会话、尝试、派发意图、租约、运行时快照和授权校验构造只读准入。未确认的进程、消息、任务结果或写权进入待对账。
2. 普通会话仅在可信恢复证据精确绑定旧会话、固定输入、规格修订、物理工作区、身份、版本和运行环境时判定原生资格。其他可判断情况要求新建尝试，可附带同任务、同项目的选定交接引用及摘要。
3. 实际 Core 定向测试覆盖原生资格、保留旧尝试、工作区变化、输入和版本不匹配、旧记录、交接范围和待对账。记录版本、固定 SHA、编译检查、范围和冲突预检。
4. 本阶段由集成窗口独审，只交付 Rust 准入。真实原生取证、会话加载、IPC 和持久化接线由后续任务承接。
