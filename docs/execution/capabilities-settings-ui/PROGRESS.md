# 实现与核验

- 能力目录读取真实具名连接以及托管 Skill、MCP 配置。列表提供类型、搜索、需核对和项目会话关联筛选。宽窗口用按需详情区，窄窗口沿用可访问弹窗。
- 保留连接登记与探测、配置前后对比、预览确认、结果核对及恢复。基础连接不可用时收起编辑字段。受审查的读取等待上一次结束再轮询，恢复结果确认后刷新目录。
- 设置采用四个横向分类。重组后台状态、登录启动、隐藏窗口、主机登记和恢复证据，沿用既有真实操作和批准。登录开关等待原生回执，未知或不支持的状态保留为独立展示。
- 独立静态审查检查了读写边界、保留既有审批和幂等、状态文案、焦点、延迟读取、重开编辑区和恢复后同步。提交前逐项核对。失败的本地运行日志保存在任务的 `artifacts/ui-checks/` 下。
- Apple Silicon macOS 26.6.1 上完成前端类型检查、生产打包、1,607 项组件测试，以及 40 项产品浏览器真实 Unix IPC 检查。生成 27 张浏览器截图。
