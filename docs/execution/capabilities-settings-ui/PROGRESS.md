## 原生设置验收跟进

PR #37 首轮 ARM64 Native 检查在登录注册烟测失败。驱动仍搜索旧版设置折叠项和登录按钮，页面改为横向标签和开关后无法进入该流程，下游集成证据和开发包因此未验证。保留原失败记录和要求，修改测试驱动以操作新版控件。驱动继续校验回执文字、禁止变更状态、冲突负控，并检查开关的观察值与操作方向。

本机通过 Rust 格式检查、范围检查及从 Rust 模板展开的 JavaScript 控件分支测试。此前通过的 1,607 项前端测试、40 项浏览器检查未覆盖 macOS 真实登录确认。更新后的实际原生烟测由 PR 检查重新验证。
