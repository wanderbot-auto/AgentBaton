## ADR: separate before-copy test seam

Keep the previous preview gate module/tests byte-identical. Use a separate small private copy gate and filenames rather than change the existing preview semantics or expose a generic test-control endpoint. Config is a selector, never source/destination/approval authority. The callsite waits only after original Owner record, actual reverified snapshot and managed-root check; marker binds actual creation/project. Snapshot approval_reference remains original preview ID and is not falsely equated with creation ID.

Only original cancellation/deadline releases the first match. No success override, copied-byte fabrication, timeout reset, Actor wait or external release switch. Claim before-copy cooperative cancel/join only; actual partial-write/mid-copy/OS-stop coverage stays separate. Same-user hostile mutation and blocking kernel calls are not sandbox/hard-interrupt guarantees.
