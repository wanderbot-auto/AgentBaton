Local ref adoption refuses any known checked-out target; it never pushes or bypasses remote protection. No stash/reset/force checkout is used. Same-user uncoordinated filesystem/Git mutations still require caller fencing/reconciliation; directory permissions/worktrees are not OS sandboxes. Partial checkout failure can leave diagnostic objects/worktree state; this layer does not delete unknown files to conceal failure.
