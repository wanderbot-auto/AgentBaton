# AB-SEC-009 数据来源

- `Store::preview_project_history_retention` 在同一读取事务中基于已注册项目读取 `conversation_turns` 和 `session_turns`。只输出稳定 ID、类型和决策。正文与重放载荷不会进入返回值。
- 回合通过显式父记录归属项目。会话再核对 Task 与持久派发关系。对话使用持久派发与已有 Goal planning provenance。会话的既有 Goal、Factory 关联参与活动判断。已知所有者冲突会拒绝预览。
- 已识别的正文回合在活动时保留，状态未知时也保留。分类无法核实时保留为 `Unclassified`。当前 Store 缺少已确认的 Pin 和完整衍生清单，即使已确认停止也只出具保留决策。
- 项目策略来自具体预览请求。现有通用配置与工作区 Pin 不属于逐条历史 Pin。回合行缺少独立时间戳。混合 journal 含规范化事件、状态和重复记录，保留原结构，未作为正文候选，也未将事件时间推断为独立捕获时间。

保护项与混合日志、外部数据、独立报告、验收及源文件不在本次回合清单中。索引、向量、缓存、导出和备份缺少可确认的逐条衍生关联及清单完备性证据，不能将未发现链接理解为空清单。
