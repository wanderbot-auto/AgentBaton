# Independent Task delegation, unchanged execution grants

Factory approval grants bounded Task decomposition only. It is not a retrospective upgrade of an existing Goal scope or ExecutionGrant. Initial descendants reuse the same unchanged root ExecutionGrant and existing approved connection/workspace; ancestor, project, root, host and global execution limits remain applicable. ExecutionGrant.max_depth/max_children still constrain Grant derivation, not Factory Task trees. The original delegate_grant API continues rejecting depth0 grants. Factory has its own independently approved Task depth, per-parent fanout and total-node ceilings; each child further narrows the parent Task budget. A legacy Goal or Grant alone cannot mint a scoped handle or child Task.

The approval snapshot shows both the unchanged original grant and the new Task-delegation capability with distinct authority labels. Future new-workspace, child Goal or child planning capabilities require their explicit complete contracts; the initial unsupported fields are rejected, never silently activated. Starting is a separate idempotent action after approval. Approval alone starts neither Provider nor MCP companion.

The fixed companion receives only a private per-session credential reference, never the daemon's general token. Four scoped methods are independent of owner IPC. A request's caller/root/project/attempt/fence come from the checked handle. Renderer-controlled fields, Provider names, repository instructions and tool output cannot supply these identities. All selected source snapshots and handoffs remain point-in-time observations, not an OS sandbox, DLP or continuous freeze.

A waiting label never releases an actual process, lease or reservation. Initial execution is sequential: parent completes its turn and is truly reaped, then child runs, then a new parent attempt consumes explicit, hash-bound handoff references. This does not claim native context restoration. Unknown processes or effects stay fenced across restart and are not retried with a new key.
