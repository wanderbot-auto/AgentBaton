# 10 · 长期运行、扩展与产品维护

## 1. 本地数据与隐私

核心功能不依赖Baton云账户；元数据、产物索引和偏好存本地。Provider 自身可能联网处理上下文，Local-first 不表示所有 Agent 推理都在本机，也不保证数据永不离开设备。任务发出前展示数据去向与执行者，尊重原生服务的隐私与授权方式。

完整历史本地保存。详细正文与日志采用可调整到期策略，当前工作默认90天（批准粒度见D04），项目可覆盖或永久保留。摘要/验收、独立报告、采纳成果与源文件分开，不受正文TTL直接删除。敏感项目可关闭正文。清理同步处理搜索索引与衍生缓存，保留缺口标记。

遥测默认关闭，选用时只发明确公开的最少指标；诊断导出本地预览，用户选择上传。删除数据和卸载需说明是否保留原生 CLI 配置、Agent历史及项目文件。

## 2. 扩展机制

扩展分为声明式 Provider manifest、原生驱动插件、外部工具打开适配器、验证器和 workflow 模板。每种扩展有版本、来源、许可、所需权限和兼容声明。纯声明导入不执行代码；代码型扩展需更高信任并按隔离能力说明风险。

优先稳定 schema 和接口，不为追求插件数放开任意主进程代码执行。扩展市场不是本产品必需功能；可从本地/Git revision 导入并验证。

## 3. 远程 Host 的完整扩展面

D05已批准远程macOS/Linux个人主机，属于完整产品核心，而非等待未来批准的可选规划。用户自行提供主机；Baton不创建云机器、不自动承担费用、不支持未批准远程Windows。

Host注册绑定身份、公钥/主机证明、目录映射、可用Agent连接和资源限制。传输建议由认证加密通道承担，具体SSH/服务注册方案须ADR验证；不可把本地API无认证暴露到公网。私钥与Provider账号不随工作包复制。

新任务先过滤已授权Host、连接、数据接收方、隔离要求，再参考数据位置与负载评分；不可为提高效率跨越数据边界。选中后固定执行绑定与输入revision；不自动迁移正在执行的attempt。

本机绝对路径不能直接传给远端。工作区通过批准的传输/共享引用映射，传输带版本、大小、敏感等级、完整性检查。远程Agent执行日志可能暂存于远端以支持断线，不能声称字节从不离开Mac；主历史库在用户Mac，不上传Baton托管云。远端缓存按同一项目策略清理，留存到期不强制删除活跃执行必需数据，应显式pin。

远端代理在有效、有期限的执行授权与预算内运行，保留本地事件journal和idempotency key。本机离线时，不得让远端新建超授权子任务或执行尚未批准生产发布。需要跨Host新调度而控制端不可用时等待。重新连接按sequence与attempt identity补齐并对账，不把断线当失败重派。取消离线时为cancel_requested，UI解释远端可能仍运行；预批准lease/截止条件到期后远端停止新副作用。

最小网络架构不等于高可用集群；不承诺无网络跨主机实时审批或全局exactly-once。

## 4. 团队能力的边界

可设计共享模板、脱敏证据、项目 Profile 与审查协作，但不能强制上传个人凭据或完整会话。团队权限、组织策略和审计留存需要单独的服务端、授权、治理与商业验证。

完整单人产品不依赖团队后端。本地核心开源、增值可商业化已经确认；完整企业多租户/治理平台没有被自动加入当前范围。保留团队扩展边界，不让个人远程执行依赖团队后台。

## 5. 能力兼容性维护

维护版本矩阵：Provider/adapter/协议/OS/架构/测试日期/支持项/限制。新版本先进入兼容性验证，不自动把旧版证据延伸。托管安装按批准更新策略自动准备经过测试的组合，新任务使用新版本，活跃attempt不变；复用本机程序检测外部版本变化，不替用户升级全局安装。

上游 breaking change 用 ADR 与测试样例记录。兼容性问题提供脱敏诊断包，可复现输入和规范化事件，不要求用户贴全部私密对话。

## 6. 可观测性与性能

记录自身启动、队列、数据库、事件延迟、worker故障、配置事务与恢复指标；分别统计 Baton 与子 Agent 资源。高流量压力测试包含多个会话、大日志、长运行与大产物；不把日志无限保留在内存。

性能目标按参考设备、并发规模、数据规模批准；自动化在固定环境对比回归，不用单次机型结果推断所有 Mac。稳定性测项覆盖长时间 idle、频繁睡眠唤醒、CLI升级与断网重连。

## 7. 体验与产品治理

功能进入产品的判据：是否直接改善会话可见、能力可理解、接力可靠或验收效率；是否原生 Provider 已经很好解决；是否引入新的配置源和重复界面；维护责任是否清楚。

完整设计不等于所有按钮都默认显示。采用渐进披露，简单用户完成基础任务无需接触 DSL、原始 JSON 或复杂图编辑。

## 8. 开源与品牌

代码许可证、第三方依赖许可、分发 adapter/CLI 的权利、商标与产品名可用性必须另行确认；本包没有进行商标检索，也不宣称 AgentBaton 名称已可注册。本地核心开源可独立使用、增值可商业化、强调改进回馈已确认；具体许可与商业模块边界尚未审定，不由编码Agent直接选择或生成生效LICENSE。

贡献指南、行为准则、漏洞报告入口、版本策略、发布权限和维护者审查纳入正式仓库治理。复用开源项目时记录来源和许可，不按“开源就可以随便复制”处理。
