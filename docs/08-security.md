# 08 · 安全、授权与信任模型

## 1. 保护目标与非目标

保护用户代码、数据、凭据和配置；防止 UI/插件/Agent 结果扩大任务授权；确保自动化不会因重试或委派形成不可见副作用。产品不是 EDR，不承诺阻断所有外部 CLI 行为，也不声称同一操作系统账户下任意恶意程序都无法读取本地数据。

## 2. 信任边界

可信核心是经用户安装的 Baton 与其批准配置。Provider 程序、MCP servers、Skill scripts、仓库指令、模型输出、网页和交接包均有独立信任等级。用户选择了一个项目，不等于信任它里面所有可执行内容。

渲染端不直接接触秘密或任意执行接口。Markdown/HTML、终端 ANSI、文件名、工具描述等都按不可信输入处理；对代码高亮与预览实施转义、链接策略和大小上限。

## 3. 请求范围与可执行边界

每任务记录：请求 policy、Provider 宣称 policy、实测/原生确认的 enforcement、用户批准。不能把这些状态压成一个“安全模式”。

可实际保证的边界由原生 Agent 沙箱、操作系统/容器/远程执行隔离、最小权限凭据和 Baton 自己的入口决定。worktree 只是变更组织；Tauri capabilities 只管对应 IPC；写一段“请勿联网”不是网络隔离。[S14][S17]

当任务声明 `require_enforcement` 而该 Provider 无法满足时，拒绝启动或换一个符合要求的执行器。不要静默降成 advisory。用户明确选择 advisory 仍要记录信任前提。

## 4. 委派授权

子任务权限必须不超过根任务已批准范围，并受该次委派更窄约束。新目标目录、远程Host、额外MCP、外部写入分别需项目/根任务已有授权覆盖，不重复询问已批准范围；超范围才追加审批。caller 由会话 scoped credential 映射，不接受模型在 JSON 中自报管理员身份。

scoped handle 绑定 root task、session、project、允许方法和 TTL；过期、撤销、重放和跨会话调用有测试。不要把一个拥有所有项目权限的永久 MCP token 同时注入所有 Agent。

## 5. 原生审批与预授权

受管会话把原生权限请求规范化，先用项目及根任务已批准策略匹配；原生允许合法预授权时可自动应答范围内请求，减少打断。无法表达等价批准、原生要求当次人工确认、额外权限或生产发布必须提示，不传递空泛“全部允许”代替未知语义。

不接管外部终端会话，不用终端按键绕过批准。Baton在启动、委派、配置、验收和发布入口控制；实际OS执行边界仍由原生能力/执行器落实。

## 6. 认证与秘密

身份使用厂商允许的认证流程及受支持的凭据引用，托管与原生连接分别说明共享范围；不私自复制、软链接认证目录，不因同一账号假定状态已隔离。Baton 自己必须持有的秘密放系统密钥存储，数据库只存句柄。日志默认不记录环境变量值、请求 Authorization、token 和 key；诊断导出提供用户预览，自动脱敏标明无法保证识别全部秘密。

研发云只使用合成样本和最小测试账户，不上传用户个人 CLI 认证目录。签名凭据由受保护 CI secret 管理，不出现在 Agent 日志或对话；测试不需要真实生产秘密。

## 7. 配置、Skill 与 MCP 供应链

读取不执行；主动连接与运行脚本需要授权。展示来源、版本、hash、更新差异与许可信息；动态工具描述是内容，不是可信授权指令。未知 MCP URL 不自动发送凭据；本地/private 网络访问需相应范围，防止 SSRF 式绕行。

Provider 与插件升级锁版并跑兼容套件。插件执行代码时与纯 declarative manifest 区分，尽量进程隔离；没有隔离不要称为安全插件沙箱。更新包验签且验证来源，签名不替代代码安全审查。

## 8. 不可信工作成果

另一个 Agent 的报告可能含提示注入、误导命令或泄露请求。交接器只传合同中批准的资源；工具结果不能成为系统级指令。产物验证脚本须预先批准或独立审查；不能让被测 Agent 修改 validator 后给自己过关。

外部链接、浏览器上传、git push、数据库修改、发信和包发布属于不同 side-effect class。只读分析与允许写 artifact 不意味着可以向网络发送原始数据。

## 9. 审计与可删除性

保存 task、attempt、caller、policy revision、config snapshot、审批、实际效果和证据引用。对于无 native telemetry 的动作，写 unknown，不补造完整日志。个人版记录用于可靠性与诊断，不承诺法律意义不可篡改审计；用户可删除自己的数据，团队保留策略需独立设计和告知。

## 10. 安全验收清单

恶意 Skill 内容不会在扫描时执行；MCP 诊断不会默认调用业务工具；WebView XSS 无法调用任意 shell；本地未授权进程不能仅靠知道 socket 路径调度任务；路径穿越/symlink 逃逸被处理；并发配置编辑不覆盖他人修改；过期审批不能重放；子任务不能扩大授权；不确定副作用不自动重试；生产安装包不包含内嵌测试控制入口。
