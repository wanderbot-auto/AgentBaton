# AgentBaton

面向开发者的多 Agent 本地控制工作台。

## 当前阶段：仅准备开发与测试环境

本仓库正在导入用户已确认的 Design v0.2 与环境准备文件。**用户尚未批准启动产品功能开发。**

允许：仓库初始化、设计校验、开发工具链与 CI 环境检查、Codex Cloud 环境准备。

禁止：启动产品长程任务、调用真实 Agent 账号、自动开启收费资源、部署或发布产品。环境准备完成后必须向用户报告，并等待新的明确确认。

目标仓库：`wanderbot-auto/AgentBaton`；默认分支：`main`；保持私有。

本初始提交用于建立安全执行边界；环境文件和检查结果将以实际执行证据更新，不能将准备脚本视为已运行的 CI 或已发布的 Cloud 环境。
