# Managed configuration transaction primitive

`agentbaton-config` implements part of WP07. It does not authorize a request, parse native Provider configuration, import credentials, discover global files, reload a Provider or expose a UI/IPC API.

A trusted daemon-side registry must resolve an approved, **non-secret** managed configuration root and classify replacement bytes before calling this crate. `ManagedRoot::open(canonical_path, Ownership::BatonManaged)` requires an existing owner-only directory. `Ownership::NativeConnected` is rejected, preserving native configuration as read-only. Passing an enum is not proof of authorization; do not expose this constructor or arbitrary paths to renderer/Agent requests.

1. `plan(Vec<Edit>)` reads exact existing bytes, checks expected SHA-256 (`None` means expect missing), rejects duplicate/unsafe paths and computes metadata-only previews. The full-file replacement must be explicitly approved; unknown fields/comments are never automatically reformatted or silently stripped by this library. A caller unable to safely preserve them must refuse its own transform.
2. `apply(ChangeSet)` serializes Baton writers, checks every baseline, saves private exact backups and a versioned manifest, then writes/fsyncs private temporary files and atomically renames each file. Multi-file changes are **not** globally atomic. The returned report records each file's state; a later failure stops subsequent writes and remains recoverable.
3. `recover(id)` reconciles pending journal entries from exact current hashes. It does not replay unknown writes or assert runtime reload success.
4. `rollback(id)` verifies backup hashes and current replacement hashes before conditional compensation. External edits are conflicts and are never knowingly overwritten. Rollback of new files removes only the matching generated file.

All paths below the root are traversed relative to opened directory descriptors with `O_NOFOLLOW`; files must be regular, owner-only, single-link and bounded to 1 MiB. Paths with traversal, symlinks, hardlinks or reserved transaction names are rejected. Parent subdirectories must already exist and be private. No content values appear in previews, reports or error strings. Backups intentionally retain exact **non-secret** bytes with mode 0600 under a mode 0700 root. Secret-bearing source files require a separate encrypted-backup/credential policy and must not be passed here.

The root private directory and process are trusted. These mechanisms do not sandbox an attacker already controlling the same OS user; portable hash-then-rename cannot provide atomic CAS against a malicious uncoordinated writer under that account. Legitimate external changes present at a check are rejected; filesystem I/O after a write can still be uncertain and requires recovery. ChangeSets and persisted journals are bound to the original root device/inode; they cannot be applied or rolled back against another connection root with coincidentally identical content. A restored root on a different inode requires an explicit new plan rather than silently replaying an old transaction. Private orphaned temporary files after low-level failure require future retention/cleanup integration.

Tests use only temporary non-secret files: normal apply/restart/rollback, concurrent writers and drift, multi-file partial failure, pending crash intent, corrupted backup, native ownership/private permission rejection, traversal/symlink rejection, cross-root plan/journal rejection and bounded writes. Linux tests do not establish macOS native behavior or Provider syntax compatibility.
